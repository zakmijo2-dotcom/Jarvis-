# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in **J.A.R.V.I.S Android** a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming, respectful, and constructive technical language.
- Being open to evidence-based code reviews and architectural feedback.
- Respecting user privacy, security boundaries, and responsible disclosure.
- Focusing on what is best for the open-source community and end users.

Examples of unacceptable behavior:

- Harassment, personal attacks, trolling, or insulting comments.
- Publishing others' private information (doxing) or leaking user credentials.
- Submitting intentionally malicious code, hidden telemetry, or backdoors.
- Other conduct which could reasonably be considered inappropriate in a professional open-source environment.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards and may remove, edit, or reject comments, commits, issues, and pull requests that violate this Code of Conduct.
