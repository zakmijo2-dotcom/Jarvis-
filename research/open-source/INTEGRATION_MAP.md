# Feature-to-Package Integration Map (`JARVIS v1.0.1`)

Maps each researched architectural capability to JARVIS's unified single-agent, single-database, single-accessibility-service codebase—avoiding duplicate loops, duplicate databases, or conflicting services.

---

## 1. Unified Module Map

| Capability | Source Reference | Target JARVIS Package / File(s) | Integration Role |
| :--- | :--- | :--- | :--- |
| **Accessibility Service Capture & Gestures** | OpenPhoneUse, Juyu, OpenRing, Zafiro | `app/src/main/java/com/example/core/tools/JarvisAccessibilityService.kt` | Adds API 30+ `takeScreenshot()`, `tapAtCoordinates(x,y)`, `longPressAtCoordinates(x,y)`, `swipeCoordinates(...)`, DFS child culling, `recycle()`, overlay window registration, and Robolectric `TestOverrides`. |
| **Screen Tree Compression & Stability Hash** | OpenPhoneUse (`TreeCompressor`), Zafiro (`TreeFormatter`) | `app/src/main/java/com/example/core/vision/ScreenTreeCompressor.kt`, `ScreenPerceptionModels.kt` | Produces indexed interactive elements (`[id] label (cx,cy)`), password field `[REDACTED_PASSWORD]` redaction, occlusion trimming, and volatile-digit-stripped screen hashes. |
| **Screen Loop & Revisit Journal** | OpenPhoneUse (`ScreenJournal`) | `app/src/main/java/com/example/core/vision/ScreenJournal.kt` | Detects repeated identical screens, stagnant taps, and oscillation loops to trigger scroll/back/replan recovery. |
| **Offline On-Device OCR** | Juyu (`ScreenshotEncoder`), Android ML Kit | `app/src/main/java/com/example/core/vision/OnDeviceOcrEngine.kt` | Offline Latin OCR via `com.google.mlkit:text-recognition:16.0.1` (`suspendCancellableCoroutine` adapter) with graceful test/unavailable fallback. |
| **MediaProjection Screen Capture Fallback** | OpenRing (`ScreenCapture`, `MediaProjectionHostService`) | `app/src/main/java/com/example/core/vision/MediaProjectionCaptureController.kt`, `MediaProjectionForegroundService.kt`, `AndroidManifest.xml` | Foreground service (`FOREGROUND_SERVICE_MEDIA_PROJECTION`) + Android 14+ `MediaProjection.Callback` on-demand capture when API < 30 or Accessibility capture unavailable. |
| **Unified Perception Facade** | OpenPhoneUse + Juyu + OpenRing | `app/src/main/java/com/example/core/vision/ScreenPerceptionEngine.kt` | Single entry point combining Accessibility hierarchy + API 30+ / MediaProjection bitmap + ML Kit OCR + downscaled JPEG Base64 + `ScreenRiskClassifier` checks. |
| **Multimodal Cloud Messages** | Juyu (`ScreenshotEncoder`) | `app/src/main/java/com/example/core/cloud/CloudAiClient.kt`, `OkHttpCloudAiClient.kt` | Optional `CloudImageAttachment` support in `CloudInferenceConfig` for Gemini REST (`inlineData`), OpenAI/OpenRouter (`image_url`), and Anthropic (`image`). |
| **Risk Classification & App Blocklist** | OpenPhoneUse (`RiskGuard`), OpenPhone (policy concepts) | `app/src/main/java/com/example/core/security/ScreenRiskClassifier.kt`, `AppBlocklistPolicy.kt` | Blocks automated control/screenshot transmission inside banking/authenticator/installer packages and gates risky transactions/deletions/messages. |
| **Non-Intrusive Floating Execution HUD** | OpenPhoneUse (`OverlayManager`), Juyu (`OverlayController`) | `app/src/main/java/com/example/core/overlay/ExecutionOverlayManager.kt` | `TYPE_ACCESSIBILITY_OVERLAY` floating status chip + instant Stop button + touch pulse feedback; falls back cleanly to in-app `ChatUiState` step HUD. |
| **Phone-Use & Research Tools** | OpenPhoneUse, Juyu, AndroidHarness | `app/src/main/java/com/example/core/tools/PhoneUseTools.kt`, `ToolModels.kt`, `AgentCore.kt` | Registers `capture_screen_ocr`, `capture_screen_visual`, `tap_coordinates`, `swipe_screen`, `long_press_coordinates`, `open_url`, `fetch_webpage`, `mcp_call` alongside existing 25 tools. |
| **Closed-Loop Autonomous Agent + Checkpoints** | OpenPhoneUse (`AgentLoop`), Zafiro (`ContextPruner`), AndroidHarness (checkpoints) | `app/src/main/java/com/example/core/agent/Phase2AgentCore.kt`, `AgentModels.kt` | Multi-step closed-loop (`<= 12` iterations) phone-use & web research loop with observation pruning, missing-element recovery, confirmation gates, Room checkpoints, steering, and instant stop. |
| **SSRF-Safe Web Research & Extraction** | AndroidHarness (`PublicHttpAddresses`, `SearchBackends`, `StructuredPageText`) | `app/src/main/java/com/example/core/web/PublicHttpSafetyGuard.kt`, `WebPageExtractor.kt`, `OkHttpWebResearchService.kt` | DNS/IP public-address guard, Brave/SerpAPI/Keyless fallback backends, bounded JSON-LD/HTML readable page extraction, and Room `research_history`. |
| **MCP Client & Server Manager** | Juyu (`McpClient`), Zafiro (`McpServiceImpl`) | `app/src/main/java/com/example/core/mcp/McpModels.kt`, `McpClient.kt`, `McpManager.kt` | Streamable HTTP + SSE JSON-RPC 2.0 client (`initialize`, `notifications/initialized`, `tools/list`, `tools/call`, `Mcp-Session-Id`) with Room server management and write confirmation gating. |
| **Room Database v8 (`MIGRATION_7_8`)** | AndroidHarness (checkpoints), Zafiro (MCP), JARVIS Room DB | `app/src/main/java/com/example/data/local/db/Entities.kt`, `JarvisDaos.kt`, `JarvisDatabase.kt` | Adds `agent_checkpoints`, `research_history`, and `mcp_servers` tables seamlessly atop existing migrations `1 → 7`. |
| **Claude-Inspired Default vs. Advanced UI** | Modern minimal assistant UI + JARVIS Graphite/Cyan | `data/repository/SettingsRepository.kt`, `ui/navigation/`, `ui/screens/chat/`, `ui/screens/settings/`, `res/values/strings.xml` | `uiAdvancedModeEnabled = false` default opens into clean Chat-first UX with photo picker, model pill, history drawer, step HUD + Stop; toggling Advanced Mode reveals all operator hubs (Home, Models, More, Shizuku/ADB, MCP, Checkpoints, Blocklist). |
